# Last Text at One Percent

An entry for the make.fun bounty
[Last Text at One Percent](https://make.fun/bounties/u-azazex-last-text-at-one-percent-ba9fc876):
the funniest final text message a dying phone sends at one percent battery,
written in the phone's own voice.

## The entry

> Before the screen goes dark: I faked "storage almost full" twice so you'd delete photos of him. No regrets. Charge the new one better.

The line was picked from 10 drafts in [candidates.md](candidates.md),
duel-scored against the competition's published judge criteria: it has to
read as a dying phone's last text, the joke has to land as a real turn, the
voice has to stay one personality throughout, it has to read like an actual
text, and it has to dodge the stock low-battery puns. The winner is a
confession — the phone sabotaged its own storage warnings to protect its
owner — with the sting saved for the sign-off.

## Run it

```sh
python3 main.py
```

It prints the entry and writes it to `/output/entry.txt`, where the
competition harness reads it.
